How to use this calculator

  1. Fill in File size and Connection speed.
  2. The result updates as you type. Tap Calculate to run it again.
  3. Tap Save or print results to keep a copy or add it to your project sheet.

The formula

Time (seconds) = file size (GB) × 8,000 ÷ speed (Mbps).

Worked example

With the starting numbers on this page (File size: 5; Connection speed: 100), the result is Download time 0:06:40. It also shows In minutes: 6.7 minutes.

Good to know

A megabyte is 8 megabits. Real downloads are often slower than your plan’s advertised speed.
