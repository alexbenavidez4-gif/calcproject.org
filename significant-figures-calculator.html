How to use this calculator

  1. Fill in Number and Significant figures.
  2. The result updates as you type. Tap Calculate to run it again.
  3. Tap Save or print results to keep a copy or add it to your project sheet.

The formula

Count digits starting from the first non-zero digit, keep the number you want, and round the last one.

Worked example

With the starting numbers on this page (Number: 0.0045678; Significant figures: 3), the result is Rounded 0.00457. It also shows Scientific notation: 4.57e-3.

Good to know

Leading zeros are never significant. Zeros between other digits always are.
