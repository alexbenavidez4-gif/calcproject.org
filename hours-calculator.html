How to use this calculator

  1. Fill in Start time, End time and Unpaid break.
  2. The result updates as you type. Tap Calculate to run it again.
  3. Tap Save or print results to keep a copy or add it to your project sheet.

The formula

Hours = end time − start time − break. If the end time is earlier than the start, the shift is treated as running past midnight.

Worked example

With the starting numbers on this page (Start time: 08:30; End time: 17:15; Unpaid break: 30), the result is Time worked 8 h 15 min. It also shows Decimal hours: 8.25 hours; Total minutes: 495 minutes.

Good to know

Payroll uses decimal hours. 8 hours 15 minutes is 8.25 hours.
