The formula

One-tailed p = area of the normal curve beyond |z|. Two-tailed p = twice that.

Worked example

With the starting numbers on this page (Z-score: 1.96), the result is Two-tailed p-value 0.0500. It also shows One-tailed p-value: 0.0250.

Good to know

A small p-value means the result would be unlikely if there were no real effect. It does not measure how large the effect is.
